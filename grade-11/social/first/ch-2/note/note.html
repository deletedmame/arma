Unit 2: Characteristics and Classification

2.1 Characteristics of Living Things

All organisms display seven life processes (MRS GREN): Movement, Respiration, Sensitivity, Growth, Reproduction, Excretion, and Nutrition.

2.2 Taxonomy of Living Things

Taxonomy involves the identification, naming, and classification of species.

2.2.1 Principles of Classification

Classification is the process by which scientists group living organisms based on how similar they are.

2.2.2 Taxonomic Hierarchies

Life is organized into a hierarchy: Kingdom → Phylum → Class → Order → Family → Genus → Species.

2.3 Relevance of Classification

Classification provides a common language for biologists and helps track evolutionary relationships.

2.4 Linnaean System of Nomenclature

The Binomial system gives every organism a two-part scientific name (e.g., Panthera leo for a lion).

2.5 Common Ethiopian Animals and Plants

Examples include the Gelada Baboon, Mountain Nyala, and the indigenous Enset plant.

2.6 The Five-Kingdom System

2.6.1 Kingdom Monera

Prokaryotic organisms like bacteria.

2.6.2 Kingdom Protista

Eukaryotic, mostly unicellular organisms like Amoeba.

2.6.3 Kingdom Fungi

Decomposers like mushrooms and molds.

2.6.4 Kingdom Plantae

Multicellular autotrophs (plants).

2.6.5 Kingdom Animalia

Multicellular heterotrophs (animals).

2.7 Renowned Taxonomists in Ethiopia

Ethiopian scholars have played key roles in documenting the local biodiversity, particularly through the Ethiopian Flora Project.
